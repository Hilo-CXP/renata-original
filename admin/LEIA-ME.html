Painel admin — servidor necessário

Este painel não funciona abrindo o arquivo direto no navegador ou com Live Server. É preciso iniciar o servidor Node.js.
  1. Instale o Node.js: nodejs.org (versão LTS)
  2. Na pasta do projeto, dê duplo clique em iniciar.bat
  3. Acesse http://localhost:3000/admin/login
  4. Login: admin · Senha: AltereSenhaForte123!
